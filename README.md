# Reducing Identity Fraud Without Losing Good Customers

**Can financial institutions stop more fraud without making onboarding harder for genuine customers?**

An evidence-led advisory research project exploring US digital onboarding, existing fraud controls and the economics of reducing manual reviews.

## What did I investigate?

**01 · Understand the problem**  
Analysed selected CFPB consumer complaints and FTC fraud and identity-theft data.

**02 · Examine existing solutions**  
Reviewed identity verification, risk scoring, workflow orchestration and manual-review alternatives.

**03 · Test the economics**  
Built an interactive Python model to estimate the potential value of reducing manual reviews.

**04 · Challenge the assumptions**  
Checked numerical claims, distinguished vendor-reported outcomes from independent evidence, and identified what still needs validation.

## A look at the economics

<sub>Illustrative scenario from the model, not a verified customer business case.</sub>

| Assumption or output | Example |
|---|---:|
| Annual manual reviews | 50,000 |
| Assumed reduction in reviews | 25% |
| Loaded cost per review | $7.02 |
| Annual vendor fee | $50,000 |
| One-time implementation cost | $30,000 |
| Gross annual labour value | **$87,750** |
| Annual net benefit | **$37,750** |
| First-year net benefit | **$7,750** |

The result changes when the assumptions change. Released staff capacity is not automatically a cash saving, and these figures have not been validated with a financial institution.

## My current point of view

**Investigate further. Do not recommend a launch yet.**

Public data establishes that fraud and identity theft are significant reported problems. It does **not** prove that lenders have an unresolved onboarding gap, that existing solutions are inadequate, or that another solution would generate a positive return.

The next step is to validate the problem with actual buyers, examine their existing controls, obtain operational data and test the economics using institution-specific inputs.
